# VoronoiShortestPathSolver

母点をいくつか置くと、平面がその数だけの領域に割れる。これがボロノイ図だ。
境界線には性質があって、どの母点からも等しく遠い点だけが並んでいる。
だから障害物を母点として置いてやれば、その境界をたどるだけで、障害物から最も離れた道が
自動的に引ける。壁にぶつからない経路が、図を作った時点でもう出来ている。それを最短経路探索に
使えないか試したのがこれ。

授業「ビジュアルコンピューティングのための幾何学」で扱った内容がもとになっている。1 週間で書いた。

C++ / Siv3D / OpenCV。本体は `voronoi_report/Main.cpp`。
